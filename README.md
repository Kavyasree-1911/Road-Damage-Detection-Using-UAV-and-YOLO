# Automated Road Damage Detection Using UAV Images and Deep Learning

## Overview
This project uses UAV (drone) images and YOLO-based deep learning models to automatically detect road damages such as cracks and potholes.

## Technologies Used
- Python
- YOLOv5
- YOLOv7
- YOLOv8
- OpenCV
- Deep Learning
- Computer Vision
